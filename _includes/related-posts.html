{%- comment -%} Related articles by tag overlap. Pure Liquid, no plugins. Selection order: Pass 1 ("strict") - overlap counted on topical tags only. Tags used by more than a quarter of the archive ("caffeine", "sleep") are ignored: every article here is about caffeine, so those tags match any post against any other and drown out real relatedness. Pass 2 ("slug") - only runs if pass 1 could not fill the block. Counts shared words in the two slugs, minus words most slugs here share ("caffeine", "risks", "safe"...). Tags are spelled inconsistently ("sleep", "caffeine and sleep"), so slugs catch pairs the tags miss. Pass 3 ("loose") - only runs if passes 1-2 could not fill the block. Counts every shared tag, generic ones included, so a post whose tags are all generic still gets recommendations. Pass 0 ("curated") - slugs listed in the post's `related_posts` front matter, in that order, always come first. Posts with `redirect_to` are never picked: they are stubs, not articles. Within each pass the overlap threshold sweeps high to low, so a post sharing 3 tags always outranks one sharing 1. site.posts is newest-first, so ties break on recency. Seen URLs live in a delimited string because Liquid cannot append to an array; the "|" delimiters stop one URL prefix-matching another. {%- endcomment -%} {%- assign max_related = 4 -%} {%- assign
