{%- comment -%} Caffeine-sorted comparison table for a category/brand hub page (Phase 5.1). Usage: include caffeine-hub-table.html drinks=in_category `drinks` must be a pre-filtered array of _data/beverages.yml entries. Liquid's `sort` filter can't sort by a nested/computed field, so each beverage's default-serving mg is packed into a fixed-width sort key ("100080|red-bull") and the key array is sorted lexicographically, which matches numeric order because every key has the same digit width. Ranged figures (caffeine_mg_low/high) sort on the high end. {%- endcomment -%} {%- assign sort_keys = '' -%} {%- for bev in include.drinks -%} {%- assign serving = bev.servings | where: "default", true | first | default: bev.servings.first -%} {%- assign mg = serving.caffeine_mg | default: serving.caffeine_mg_high | default: 0 -%} {%- assign padded = mg | plus: 100000 -%} {%- assign sort_keys = sort_keys | append: padded | append: '|' | append: bev.slug | append: ',' -%} {%- endfor -%} {%- assign sorted = sort_keys | split: ',' | sort | reverse -%}
